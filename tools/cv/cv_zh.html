项目经历

C3：多智能体 LLM 协作的精确信用分配（第一作者论文官方实现） 2025.11 至今
问题多个 LLM 智能体协作时只有终局的稀疏反馈，单个智能体每一步决策的实际贡献被整体结果掩盖，是多智能体强化学习训练不稳定的直接来源。
方法基于对话轨迹重放的反事实评估与 leave-one-out 基线，将终局奖励还原为逐决策的精确信用；并提出与训练方法无关的信用质量审计（信用保真度、组内方差、智能体间影响三项诊断）。
工程在 A100 多卡节点上端到端跑通多智能体 RL 训练全流程；训练栈为 OpenRLHF（二次开发）+ vLLM + DeepSpeed ZeRO-2。针对多模型共存的显存瓶颈，采用训练与推理显存分时、显存占用率调优、micro-batch 与序列长度配平的组合方案；主结果以五个随机种子复现验收。
开源github.com/EIT-EAST-Lab/C3（含多智能体编排配置、复现脚本与审计工具）。
Myco：面向 AI 智能体的自进化认知基座（个人独立开源项目） 2026.03 至今
以 Rust 实现的智能体基础设施，面向 Model Context Protocol（MCP）生态，提供跨会话的持久记忆与知识管理。设计了完整的自迭代循环（吸收、演化、剪枝、再生），使智能体的记忆与能力可以跨模型更替持续积累，并配有一套自检机制保证内部状态的一致性。开源地址：github.com/Battam1111/Myco。
