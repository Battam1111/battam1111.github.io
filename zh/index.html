在强化学习里，模型是可以训练的。训练模型的环境，还不行。我想让环境也变得可训练，像模型一样，并以此把 AI 的上限抬上去。

现在agentic RL，以及训练环境到底教会了长程 agent 什么。其中一个例子写在《环境不正 Agent 歪》里。

长文 · 短片 · 代码 环境不正 Agent 歪 我翻了三份公开的 RL 训练记录，发现 agent 变歪有迹可循。
  1. 2026年11月20日
    Credit Assignment 过时了？ 方法会过时，问题不会。长程任务和 agent 的时代，恰恰是最需要专门去解 credit assignment 的时候。
  2. 2026年11月15日
    LLM 统一了输入，coding 统一了输出 前一次大一统让模型什么都能读懂，这一次让模型什么都能做出来。
  3. 2026年11月15日
    为何国产大模型训不好 RL？ 卡和 infra 之外，我认为还有一个更根本的原因，它藏在国内 RL 起步时走的那条路里。
