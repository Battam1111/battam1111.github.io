## 本组（Embodied AI / Robotics）整体 pattern 总结

**共同点**：
1. 全部极简风、几乎无装饰；最复杂的是 Dieter Fox 的 WordPress 三卡片
2. Publications 都不直接列在主页，全部外链 Scholar / lab publications 页——Robotics 主页是"导航页"而非"档案页"
3. Lab 是核心身份载体（RAIL / Robot Locomotion Group / IRIS Lab / RSE-Lab）——教授主页本质是 lab 的入口
4. Research 描述都很短（1-3 句），philosophy 句明显
5. Talks 段广泛存在（YouTube channel 文化）

**差异点**：
- **selling 度光谱**：Abbeel/Tedrake（强 selling，公司身份首屏）↔ Finn（中，一处 Pi 提及）↔ Levine（极克制，几乎零 selling）↔ Fox（叙事克制但信息密度高）
- **更新机制**：Finn/Fox 有 News/Posts ↔ Levine/Tedrake/Abbeel 无明显 News
- **教学资源摆放**：Finn 单独成段（Tutorials and Lectures），其他人只是列课程链接
- **开源软件可见性**：Tedrake 把 Drake 摆显眼，其他人只链接 GitHub
- **技术栈**：Abbeel/Tedrake/Levine 是 plain HTML 90 年代风；Finn 略现代；Fox 是 WordPress

**反例**：Tedrake 的"邮箱我很少看"声明是反例——只有 senior 教授才能这么写，PhD 学生不能。Abbeel 的三重商业身份首屏堆叠也是反例——PhD 没有这个底气。

**Yanjun Chen takeaway**：
1. **务必有 News 段**（学 Finn/Fox）——PhD 主页"活着"的最强信号
2. **Publications 可以列在主页（不像教授外链）**——PhD 量不大，直接列更专业
3. **Research description 一句话化**（学 Levine 的"general-purpose methods"）——不要列 5 个方向
4. **不要 selling 商业身份**（学 Levine）——PhD 没有，硬塞实习公司只会显得不够分量
5. **开源/工具 单独 section**（学 Tedrake 的 Drake 摆放方式）——如果有 RLHF 评测工具 / reward model 仓库，这是 PhD 最强 selling
6. **不要 lab/students section**——PhD 没有这个角色，留着是 noise
