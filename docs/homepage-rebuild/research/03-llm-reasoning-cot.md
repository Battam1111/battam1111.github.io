## 本组（LLM Reasoning / CoT）整体 pattern 总结（≤300 字）

**共同点（5/5）**：
- 首屏 self-description 极短（1 句话或 2-3 件套），不堆形容词。
- 无任何动画/装饰，背景全部白底黑字（或近似）。
- 不放 "Selling impact" 语言（无 "transforming AI"、"empowering" 这类商业词）。
- Publications 是核心，反向时间序，让 paper 自证。

**差异点**：
- **Mission 写法**：Denny Zhou 用 "Solve AGI" 大野心 mission；Jason Wei 完全不写 mission，靠 blog 表态；Tushar/Sasha/Hannaneh 用研究方向 one-liner 代替 mission。
- **Blog**：Jason Wei + Tushar Khot 有独立 blog（这是 selling voice 的关键载体）；Denny / Sasha / Hannaneh 无 blog。
- **Awards section**：Hannaneh（tenured 教授）独立陈列；其他 4 人全部不独立列 awards，最多 inline 在 bio。
- **头像**：Denny Zhou 唯一不放头像；Sasha Rush 用 GitHub avatar（非正式）；其余 3 人正式头像。

**反例（要避开）**：这 5 个主页**没有一个**用了 hero banner、carousel、装饰性 SVG、滚动动效、卡片网格 publications、icon-heavy section header。这就是 reasoning 圈的"零装饰共识"。

**Yanjun Chen takeaway**：
1. **首屏抄 Jason Wei + Sasha Rush 句式**：「PhD Student. PolyU. Hong Kong.」+ 「I work on RLHF, LLM reasoning, and embodied agents.」
2. **必有 Blog tab**：这是这群里和 Yanjun 最像的角色（Jason Wei）做 selling 的关键武器，PhD 写 blog 性价比极高。
3. **不要 awards 独立 section、不要 hero banner、不要动画**——这是圈层共识。
